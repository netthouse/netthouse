# Roadmap

Netthouse is building payment and cost-attribution infrastructure for AI agents, MCP servers, and machine-to-machine services.

## Current

- Double-entry ledger
- x402 HTTP payment flow
- TypeScript and Python SDKs
- API key scopes
- Multi-currency accounts
- Automatic clearing proposals
- Dashboard and API documentation
- Base mainnet and testnet examples

## Next

- Improve the onboarding flow
- Add more SDK and integration examples
- Expand observability and usage analytics
- Improve seller and buyer dashboards
- Add production readiness and security documentation
- Work with early design partners

## Longer term

- More payment and settlement options
- Enterprise controls and auditability
- Integrations with AI agent gateways and MCP ecosystems
- Better cost attribution across agents, tasks, and projects

The roadmap is directional and may change based on user feedback and technical validation.
